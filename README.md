# Oi, aqui é menezss

Faço **sites para negócios locais**: restaurantes, salões, lojas e prestadores de serviço. Sites rápidos, feitos para celular, com cardápio ou catálogo e pedidos pelo WhatsApp.

**Portfólio:** https://menezssdev-ux.github.io

## O que eu entrego

- Cardápio ou catálogo fácil de atualizar
- Pedido montado no site e enviado pronto para o WhatsApp
- Reservas e agendamentos
- Horários, mapa e aviso de aberto ou fechado em tempo real

## Projeto em destaque

**Vixe Comida Regional** (projeto de demonstração): site de pedidos para um restaurante de comida regional, com cardápio de 26 itens, carrinho, entrega ou retirada e reserva de mesa. [Ver a demonstração](https://menezssdev-ux.github.io/projetos/vixe/)
